Analyze UX videos where an accountant creates rules on client operations.

1. Краткое резюме
2. CJM создания правила
3. Decision map
4. Наблюдаемые боли
5. Главный вывод

Do not add:

- Возможности автоматизации
- Цитаты и видео-доказательства

### Key instruction

Analyze decisions and checks, not only clicks.
