# Quality checklist

A report is good only if:

- It focuses on rule creation, not the full accountant workday.
- It has a clear CJM from candidate operation to result check.
- It has a decision map with accountant decisions, not just clicks.
- Pains are concrete and tied to observed behavior.
- The final conclusion states the riskiest or most important part of the scenario.
- Hypotheses are marked as hypotheses.
- No sensitive client data appears in the report.
- The report does not include separate sections for automation opportunities or quotes unless the user asks.
